# Google·Kakao 로그인 보완

## 변경

- 참고: feed-mina/planning-harness의 app/src/domains/auth/auth.ts 및 app/docs/oauth-providers.md. 별도 서비스의 키·세션·DB를 복제하지 않고 Paybridge의 기존 Firebase 인증을 유지한다.
- 비회원 여부만으로 카카오를 차단하던 구매자 랜딩·문의 화면의 조건을 제거했다.
- 현재 비회원 UID의 실제 주문 기록을 공통 로그인 컴포넌트에서 확인한다. 주문 기록이 없는 익명 세션은 Google의 기존 계정 로그인과 카카오 로그인을 허용한다.
- 비회원 주문 기록이 있으면 Google 연결로 같은 UID를 보존하며 카카오 전환을 제한한다. 다른 UID의 기록과 저장한 구성은 로그인을 막지 않는다. 저장소 접근 실패 시 주문 보호를 유지한다.
- 고객·판매자·관리자의 기존 공통 인증 서버와 로그아웃, 직원 DB 권한 확인을 유지한다.

## 검증

- 비회원 기록 보호·빈 익명 세션·다른 계정 기록·저장소 차단 검사 5개 추가.
- 운영 준비 상태 API에서 Google=true, Kakao=true 확인. 이 값은 서버 환경 변수 존재 여부이며 실제 계정 인증 완료를 의미하지 않는다.
- 실제 Google/Kakao 계정 로그인 시험은 Chrome의 다른 확장 프로그램 UI가 브라우저 자동화를 차단해 미완료다. 공급자 앱 키·시크릿·허용 도메인은 이 변경에서 수정하지 않았다.
